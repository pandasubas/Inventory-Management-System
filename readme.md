# 📦 Stockly – Inventory Management System

**Stockly** is a modern, responsive, and user-friendly Inventory Management System designed to help small businesses, shopkeepers, vendors, and warehouses manage their inventory efficiently.

The application provides an easy way to manage products, categories, suppliers, stock levels, and inventory reports through a clean and interactive dashboard.

## 🚀 Features

- **User Authentication** – Sign up and login functionality.
- **Dashboard** – View important inventory statistics.
- **Product Management** – Add, edit, delete, and manage products.
- **Category Management** – Organize products into categories.
- **Supplier Management** – Manage supplier information.
- **Stock Monitoring** – Track available, low-stock, and out-of-stock products.
- **Reports** – View inventory value and stock summaries.
- **Search & Filter** – Quickly find products.
- **Dark & Light Mode** – Switch between different themes.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.
- **Local Storage** – Save inventory data in the browser.

## ⚙️ Installation & Setup

Follow these steps to run Stockly on your computer.

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the project folder**

```bash
cd Stockly
```

**Step 3: Run the application**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

**Step 4: Create an account**

Register using the signup page and start managing your inventory.

## ⚠️ Important Note

This is currently a client-side application. Inventory data and authentication information are stored in browser Local Storage.

It is designed as an academic project and prototype. It should not be used to store real user credentials or sensitive business information without implementing proper backend security.
